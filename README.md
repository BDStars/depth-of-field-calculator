# 液态远心镜头 · 景深计算器

单文件交互式网页工具，用于液态远心镜头的景深（Depth of Field）估算与可测性判定。

- 纯前端实现，无任何外部依赖，打开即用
- 适配桌面端与移动端；所有计算在本地完成，数据不外传
- 在线访问：<https://bdstars.github.io/depth-of-field-calculator/>

## 功能

1. 景深计算：几何项与衍射项分列，四档口径可选（几何＋衍射相加 / 方和根 / 几何单像元 / Rayleigh）
2. 可测性判定：σ = max(DOF/15, K·σd/√N)、可分峰 h ≥ 2.5·DOF、量程 h ≤ K·R
3. 预设配置：VS-TCH4-65-LQL1（近端 / 远端）、TCALP23-06-115-12EC1

## 公式

```
δ      = p / M            物方像元
NA     = M / (2·F#)       物方数值孔径（F# 取实效值）
DOF    = λ/(2NA²) + 2δ·F#/M
σ      = max( DOF/15 , K·σd/√N )
T      = K·R              液态镜头全行程对应的物方位移
```

- DOF/15：峰位拟合的统计极限（约为峰宽 1/15）
- K·σd/√N：屈光度重复性经光学杠杆折算、再按 N 帧平均后的单点重复性
- N 为参与峰位拟合的帧数，单点测量取 N=1

## 输入参数

| 类别 | 参数 | 说明 |
| --- | --- | --- |
| 光学 | M、p、λ | 放大倍率、像元尺寸、工作波长（白光取 0.55 μm） |
| 光学 | F# 或 NA | 二选一输入，另一项自动换算；F# 须为实效（工作）值 |
| 判据 | 口径 | 决定 DOF 取哪一档，报数时必须注明 |
| 液态镜头 | R、K、σd、N | 屈光度行程、光学杠杆、重复性、拟合帧数 |
| 工件 | h | 被测台阶高度（可留空，仅看能力边界） |

## 预设

| 预设 | M | F# | K (μm/dpt) | 5 dpt 行程 |
| --- | --- | --- | --- | --- |
| VS-TCH4-65-LQL1 近（−2 dpt） | 4.00× | 18.1 | 120 | 600 μm |
| VS-TCH4-65-LQL1 远（+3 dpt） | 3.69× | 16.8 | 120 | 600 μm |
| TCALP23-06-115-12EC1 | 0.6× | 4.5 | 3600（估算） | 18000 μm |

- TCH4 的 K 取自 Optotune 样本的 optical leverage（0.12 mm/dpt），据此 5 dpt 仅 0.6 mm，测 1 mm 台阶需分段扫描或改用 Z 向滑台
- TCALP 的 K 由工作距 113～131 mm 反推，属估算值，须向厂家确认 optical leverage 后替换
